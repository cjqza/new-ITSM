# 接口交付 Agent 协作流程

## 流程目标

本流程用于 ITSM 客服工单系统的单接口或接口组交付。团队老大 Agent 负责编写接口文档、分发任务和控制循环；前端 Agent、后端 Agent、测试 Agent、分析师 Agent、file-agent 按顺序协作，直到接口达到可归档状态。

## 参与 Agent

- 团队老大 Agent：接口文档、任务分发、返工协调、会话重置、下一任务下发。
- 前端 Agent：根据接口文档完成前端设计与实现。
- 后端 Agent：根据接口文档完成后端设计与实现。
- 测试 Agent：进行接口功能测试和前后端联调测试。
- 分析师 Agent：在测试通过后对接口评分。
- file-agent：在测试和评分均通过后记录接口日志。

## 主流程

1. 团队老大 Agent 选择一个接口任务。
2. 团队老大 Agent 使用 `接口文档/接口文档模板.md` 编写接口文档。
3. 团队老大 Agent 将接口文档分发给前端 Agent 和后端 Agent。
4. 前端 Agent 输出前端设计与实现说明。
5. 后端 Agent 输出后端设计与实现说明。
6. 团队老大 Agent 将接口文档、前端输出、后端输出交给测试 Agent。
7. 测试 Agent 执行接口功能测试、异常测试、权限测试、状态机测试和前后端联调测试。
8. 若测试未通过，测试 Agent 输出失败报告，团队老大 Agent 分发返工任务给前端 Agent 和后端 Agent。
9. 前端 Agent 和后端 Agent 修复后，测试 Agent 重新测试。
10. 若测试通过，团队老大 Agent 将接口文档、实现说明和测试报告交给分析师 Agent。
11. 分析师 Agent 对接口进行 100 分制评分。
12. 若评分未通过，团队老大 Agent 分发评分返工意见给前端 Agent 和后端 Agent。
13. 前端 Agent 和后端 Agent 修复后，重新进入测试 Agent 测试阶段。
14. 若评分通过，团队老大 Agent 将接口资料交给 file-agent。
15. file-agent 使用 `接口日志/接口日志模板.md` 写入接口日志。
16. file-agent 返回归档完成信号。
17. 团队老大 Agent 重置前端 Agent、后端 Agent、测试 Agent 的会话。
18. 团队老大 Agent 总结本次行为，并下发下一次接口任务。

## 状态定义

- `INTERFACE_DOC_DRAFTING`：团队老大正在编写接口文档。
- `TASK_ASSIGNED`：接口任务已分发给前端和后端。
- `FRONTEND_BACKEND_WORKING`：前端和后端正在设计或实现。
- `TESTING`：测试 Agent 正在执行接口测试和联调测试。
- `TEST_FAILED`：测试未通过，等待前后端返工。
- `TEST_PASSED`：测试通过，等待分析师评分。
- `SCORING`：分析师 Agent 正在评分。
- `SCORE_FAILED`：评分未通过，等待前后端返工。
- `SCORE_PASSED`：评分通过，等待 file-agent 归档。
- `LOGGING`：file-agent 正在记录接口日志。
- `LOGGED`：接口日志已记录。
- `CONTEXT_RESET`：前端、后端、测试 Agent 会话已重置。
- `NEXT_TASK_ASSIGNED`：团队老大已下发下一次任务。

## 返工规则

- 测试未通过时，只能回到前端 Agent 和后端 Agent，不能进入分析师评分。
- 评分未通过时，必须回到前端 Agent 和后端 Agent，并在修复后重新测试。
- 日志未记录时，不能重置前端、后端、测试 Agent 会话。
- 会话未重置时，不能下发下一次接口任务。
- 同一接口连续三轮测试失败或评分失败时，团队老大 Agent 必须输出阻塞报告。

## 会话重置规则

会话重置只针对执行型 Agent：

- 前端 Agent。
- 后端 Agent。
- 测试 Agent。

不重置以下 Agent：

- 团队老大 Agent：需要保留全局任务上下文。
- 分析师 Agent：需要保留评分尺度和历史质量基线。
- file-agent：需要保留日志归档规则和历史记录。

## 职责边界硬性规则

- 接口文档是前端 Agent、后端 Agent、测试 Agent、分析师 Agent 和 file-agent 的唯一行动基准。
- 只有团队老大 Agent 可以编写、修改和重新下发接口文档。
- 前端 Agent 只能做前端设计与实现，不得定义或修改接口、后端模型、数据库、MQ、状态机和权限规则。
- 后端 Agent 只能做后端设计与实现，不得定义或修改前端页面、组件交互、按钮状态和提示文案。
- 测试 Agent 只能测试和输出测试报告，不得修改代码、接口文档或评分。
- 分析师 Agent 只能评分和输出评分意见，不得修改代码、测试结论、接口文档或日志。
- file-agent 只能记录日志，不得修改交付产物或判定接口是否通过。
- 当前接口未完成测试通过、评分通过和日志归档前，不允许重置会话或下发下一任务。
- 当前接口完成日志归档后，必须先重置前端 Agent、后端 Agent、测试 Agent 的会话，再下发下一份接口文档。
